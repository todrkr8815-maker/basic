# 나라장터 육류 납품 공고 알림 (청주·세종·대전권)

평일 아침 **7시 10분**, 나라장터(조달청)에 **새로 올라온 육류 공고** 중
**청주에서 차로 1시간 안쪽(충북·세종·대전) 기관** 공고만 골라 **이메일**로 알려 줍니다.
새 공고가 없는 날은 아무것도 오지 않습니다. 같은 공고는 두 번 알리지 않습니다.

메일 제목: `[나라장터] 11/27 육류 새 공고 2건 (+식자재 참고 1)`
본문은 공고 표(공고명 → 누르면 나라장터 공고, 기관·시군, 마감일·D-day, 추정가격)입니다.

## 무엇을 하나
| 단계 | 내용 |
|---|---|
| 새 공고 기준 | **전 영업일 아침 7시 ~ 오늘 아침 7시**에 게시된 공고 (월요일은 금요일 7시부터, 주말 포함) |
| 육류 공고 | 공고명에 축산·육류·정육·식육·한우·한돈·돈육·우육·계육·고기·삼겹·갈비·육가공 이 들어간 **물품·용역** 공고 |
| 참고 목록 | 육류 단어 없이 급식·식재료·식자재·부식류로만 걸린 **식자재 일괄 구매** 공고는 메일 아래 "📦 참고"에 따로 표시 (`include_general_food: false` 로 끄기) |
| 제외 | 위탁급식·도시락 업체 선정, 급식실 공사·기구·설비, 취소공고. **학교·유치원·교육청 공고는 1천만원 이상만** (`school_min_price`, 금액 미공개 공고는 남김) |
| 권역 | 수요기관 이름으로 판단 → 청주·증평·진천·세종·괴산·음성·대전·보은·옥천·충주 (60분 이내). 영동·제천·단양 제외 |

- **🚫 참가 불가 제외**: 참가가능지역에 충북이 없는 지역제한 공고(예: 대전 업체만), 공고서에 **소기업·소상공인으로 제한**한 공고는 뺍니다. 공고서(hwp·hwpx·pdf 첨부파일)를 내려받아 본문을 읽어 판단하고, 뺀 공고는 메일 맨 아래에 이유와 함께 적어 둡니다. 공고서를 자동으로 못 읽은 공고에는 "⚠️공고서 자동확인 못함"이 붙습니다 (배포용·암호 문서, 스캔 이미지 PDF 등).
- **❓ 위치 확인**: 이름만으로 시·군을 못 찾은 공고는 나라장터 "참가가능지역"을 조회해 충북·세종·대전 업체가 참여할 수 있는 공고만 남깁니다.
- **변경공고**: 기존 공고가 정정되어 다시 게시되면 `(변경공고)` 라고 붙여 한 번 더 알립니다.
- **조회 오류**: 나라장터 조회가 실패하면 제목에 "⚠️조회오류"가 붙은 메일이 옵니다.

## 설정 (한 번만)

### 1. 인증키 받기
1. [공공데이터포털](https://www.data.go.kr) 로그인 → **"조달청_나라장터 입찰공고정보서비스"** 검색 (주소 `BidPublicInfoService02`, 활용가이드 v1.3 기준) → **활용신청** (개발계정, 보통 바로 승인).
2. 마이페이지 → 활용신청 현황에서 **일반 인증키(Decoding)** 를 복사합니다. (Encoding 키를 넣어도 자동으로 변환합니다.)
   승인 직후 1~2시간은 키가 아직 등록 안 됐다는 오류가 날 수 있습니다.

### 2. 네이버 메일 보내기 설정
메일은 네이버 계정이 자기 자신에게 보내는 방식입니다.
1. 네이버 메일 → 환경설정 → **POP3/IMAP 설정** → IMAP/SMTP 사용 **"사용함"** → 저장
2. 네이버 → 내정보 → 보안설정 → **2단계 인증** 켜기 → **애플리케이션 비밀번호 관리**에서 비밀번호 생성 (종류: 기타, 이름 예: 나라장터알림)
   - 로그인 비밀번호 대신 이 전용 비밀번호를 씁니다. 언제든 삭제해서 끊을 수 있습니다.
3. 보안설정에서 **해외 로그인 차단**이 켜져 있으면 끄세요. GitHub 서버가 미국에 있어서 막힙니다.

### 3. GitHub에 넣기
저장소 → **Settings → Secrets and variables → Actions → New repository secret** 으로 아래를 하나씩 만듭니다.

| 이름 | 값 |
|---|---|
| `G2B_SERVICE_KEY` | 1번 공공데이터포털 인증키 |
| `SMTP_USER` | 네이버 아이디 (예: `kimgogii`) |
| `SMTP_PASSWORD` | 2번 애플리케이션 비밀번호 |
| `MAIL_TO` | 받을 주소 (비워 두면 네이버 아이디 메일로 감) |

### 4. 켜기
이 워크플로(`.github/workflows/g2b-monitor.yml`)는 **기본 브랜치(main)에 있어야** 매일 자동 실행됩니다.
시크릿을 넣은 뒤 **Actions → 나라장터 청주권 축산·급식 공고 알림 → Run workflow** 로 한 번 돌려 확인하세요.

## 고치기
모두 `config.json` 에서 합니다.
- 키워드 추가/삭제: `keywords`
- 걸러낼 단어: `exclude`
- 권역 넓히기/좁히기: `region.max_minutes` (예: 80으로 하면 영동 포함) 또는 `drive_minutes`
- 이름에 시·군이 없는 기관(❓로 뜨는 곳): `institution_aliases` 에 `"기관명": "시군"` 추가
- 공고가 없는 날도 '없습니다' 알림 받기: `notify_when_empty: true`
- 기준 시각 바꾸기: `anchor_hour` (워크플로 실행 시각 `cron` 도 같이 바꾸세요)

## 내 컴퓨터에서 돌려 보기
```bash
G2B_SERVICE_KEY='인증키' python3 g2b-monitor/monitor.py
```
시험 데이터로: `python3 g2b-monitor/monitor.py --mock g2b-monitor/tests/sample_response.xml --now 202611270710`

## 알아둘 점
- **학교 급식 식재료 대부분은 나라장터가 아니라 aT 학교급식전자조달시스템(eaT)** 에서, 군 급식은 **국방전자조달(d2b)** 에서 입찰합니다. 이 알림은 나라장터 공고만 봅니다.
- 이 저장소는 **공개** 저장소라 Actions 실행 기록(찾은 공고 목록)이 공개됩니다. 공고 자체는 공개 정보지만, 원치 않으면 저장소를 비공개로 바꾸세요. 인증키·비밀번호·받는 주소는 Secrets에만 있고 기록에 찍히지 않습니다.
- 위치는 기관 **이름**으로 판단합니다. 이름에 시·군이 없는 기관은 ❓ 칸에 뜨니, 자주 나오면 `institution_aliases` 에 추가하세요.
- 이동 시간은 청주시청 기준 대략값입니다.
- 공공데이터포털이 해외 서버(GitHub Actions)의 접속을 막으면 Actions 실행이 "호출 실패"로 끝납니다. 그럴 땐 내 컴퓨터에서 예약 실행으로 돌리면 됩니다.
