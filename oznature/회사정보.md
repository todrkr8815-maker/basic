# 오즈네이쳐 회사 정보

매일 홍보글을 쓸 때 **여기 적힌 사실만** 회사 주장으로 사용합니다.
여기 없는 내용(원산지, 등급, 인증, 배송 방식, 가격, 수상 경력 등)은 글에 지어내지 않습니다.

## 확인된 사실
- 회사명: 오즈네이쳐
- 판매 채널: 네이버 스마트스토어 (소비자 판매)
- 납품: 식당·업소에 고기를 납품함 (B2B)
- 판매 상품
  1. 돼지갈비 찜용
  2. 돼지갈비 포갈비
  3. 소불고기용 우목심
  4. 제육볶음용 목전지
- 상품은 용도(찜·구이·불고기·제육)에 맞춰 손질·재단된 상태로 판매함

## 핵심 메시지 (왜 우리한테 사야 하나)
- 용도별로 손질된 고기 → 사서 바로 요리할 수 있음, 손질 시간·버리는 양이 줄어듦
- 식당은 맛이 원육에서 갈림 → 일정한 원육을 공급받는 것이 메뉴 맛을 지키는 길
- 간단하고 명료하게: 한 글에 메시지 하나

## 채워주시면 글이 더 강해지는 사실 (아직 미확인 → 글에 쓰지 않음)
아래를 알려주시면 이 파일에 옮겨 적고 그때부터 글에 사용합니다.
- [ ] 원산지 (국내산 / 수입산, 국가)
- [ ] 등급·인증 (예: HACCP, 등급판정)
- [ ] 업력, 거래처 수 등 신뢰를 주는 숫자 (후킹 기법 #6에 사용)
- [ ] 배송 방식 (냉장/냉동, 당일 출고 여부)
- [ ] 납품 조건 (최소 주문량, 정기 배송, 샘플 제공 여부, 맞춤 규격 가능 여부)
- [ ] 문의 방법 (전화, 카카오 채널, DM 등)
- [ ] 네이버스토어 검색어 또는 주소
