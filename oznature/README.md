# 오즈네이쳐 회계 관리 시스템

매입·매출 자료로 **매월 경영 보고서**를 만들어 경영자가 회사 상태를 한눈에 보게 합니다.

- **보고 시기**: 매월 5일(첫째 주), 전월분
- **5일 보고서는 잠정치**: 전월분 전자(세금)계산서는 10일까지 발급될 수 있어, 10일 이후 자료가 바뀌면 다시 작성합니다.
- **기준**: 관리회계(경영 판단용). 부가세 제외, 감가상각 전. 세무 신고용 확정 수치는 세무대리인 결산이 기준입니다.
- **예시 보고서**: [`reports/SAMPLE-2026-09.md`](reports/SAMPLE-2026-09.md) (가상 데이터로 만든 견본)

> ⚠️ **실제 자료를 올리기 전에 저장소를 비공개(Private)로 바꿔 주세요.**
> 이 저장소는 현재 공개 상태라 누구나 볼 수 있습니다.
> GitHub 저장소 → Settings → General → 맨 아래 Danger Zone → Change visibility → Private

## 1. 필요한 자료

### A. 매달 받을 자료 (전월분, 매월 3일까지)

| # | 자료 | 어디서 받나 | 파일 | 보고서에서 쓰는 곳 |
|---|---|---|---|---|
| 1 | **매출 내역** | 홈택스 전자(세금)계산서·계산서 매출 목록, 스마트스토어 정산내역, 카드매출 내역, 판매일보 | `sales.csv` | 매출·채널·거래처·품목별 마진, 미수금 |
| 2 | **매입 내역** | 홈택스 매입 (세금)계산서 목록, 매입일보 | `purchases.csv` | 매출원가, 매입처 의존도, 매입단가 변동 |
| 3 | **월말 재고** (창고·품목별 kg, 금액, 입고일, 유통기한) | 월말 재고 실사표 | `inventory.csv` | 정확한 매출원가, 재고 보유일수, 장기·임박 재고 |
| 4 | **인건비** (급여대장 요약) | 급여대장 | `payroll.csv` | 인건비율, 직무별 인건비 |
| 5 | **고정비** (임차료·전기·보험·보관료·기장료 등) | 자동이체 내역 | `fixed_costs.csv` | 고정비 추이, 손익분기점 |
| 6 | **기타 경비** (법인카드·영수증: 유류비·소모품·접대비 등) | 카드사 이용내역 | `expenses.csv` | 비용 구조 |
| 7 | **통장 잔액·대출 잔액** (월말) | 인터넷뱅킹 | `cash.csv` | 현금 여력, 차입금 |
| 8 | **입금·지급 내역** | 통장 거래내역 | `sales.csv` 입금일, `purchases.csv` 지급일 | 미수금 연령, 회수기간 |

3번 **월말 재고가 가장 중요합니다.** 재고가 없으면 매출원가를 "그 달 매입액"으로 근사할 수밖에 없어
이익이 달마다 크게 출렁입니다.

### C. 받지 않는 자료

분석에 필요 없거나 개인정보라서 넣지 않습니다.

- 직원 이름·주민번호·계좌번호 → 인건비는 `직원코드`(E01 등)로만
- 주주·대표 생년월일과 개인 주소, 공동인증서·비밀번호, 카드번호 전체
- HACCP 문서·작업장 동선 (창고 이름만 재고표에 사용)

받은 엑셀을 그대로 넣으세요. 보고서를 만들 때 Claude가 아래 표준 양식으로 정리합니다.

**방법 2 — 양식에 직접 입력**: `data/*.csv`에 행을 이어 붙입니다. 엑셀에서 "CSV(쉼표로 분리)"로 저장하면 됩니다.
금액의 쉼표·"원"은 있어도 되고, 날짜는 `2026-10-05`, `2026.10.05`, `20261005` 모두 읽습니다.

## 3. 보고서

```bash
python3 oznature/report.py 2026-10
```

`oznature/reports/2026-10.md`가 만들어집니다. 파이썬 기본 기능만 써서 따로 설치할 것은 없습니다.

| 순서 | 내용 |
|---|---|
| 1. 한눈에 보기 | 매출·매출총이익·영업이익·판매 중량·현금, 전월·전년 동월 대비, 작년 결산 대비 |
| 2. 경영자 체크포인트 | 매출 급감, 이익률 하락, 영업손실, 거래처·매입처 쏠림, 장기 미수, 현금 부족, 손익분기점 미달, 역마진 품목, 목표 미달 |
| 3. 손익 요약 | 월 손익표, 상품/제품별 이익, 목표 대비, 최근 6개월 추이 |
| 4. 매출 분석 | 채널별, 거래처 순위·신규·이탈, 품목별 kg당 마진 |
| 5. 매입·원가 | 매입 구분, 매입처 순위, 매입단가 ±5% 변동 품목 |
| 6. 비용 구조 | 인건비(직무별), 고정비, 기타 경비, 손익분기점 |
| 7. 자금·채권·채무 | 현금 여력, 미수금 연령·상위 거래처, 재고 보유일수·유통기한 임박·장기 재고 |
| 8. 부가세·세무 일정 | 분기 누계 예상 부가세(면세 겸영 안분), 다음 달 신고 일정 |
| 자료 점검 | 빠진 파일, 읽지 못한 행, 빈 값 |

### 계산 기준

- **매출원가**: 월말 재고가 있으면 `기초재고 + 원가성 매입 − 기말재고`. 없으면 품목 표준원가, 그것도 없으면 그 달 매입액으로 근사(보고서에 방식 표시).
- **영업이익(감가상각 전)**: 매출총이익 − 판매수수료 − 인건비 − 고정비 − 기타 경비. 차량·설비 구입(`자산`)은 손익에서 뺍니다.
- **작년 대비**: 재무제표는 제조경비를 매출원가에, 감가상각비를 판관비에 넣으므로 같은 기준으로 맞춰 비교합니다.
- **손익분기점**: 인건비+고정비 ÷ 공헌이익률 (변동비 = 매출원가 + 수수료 + 기타 경비).
