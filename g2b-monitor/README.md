# 나라장터 청주권 축산·급식 공고 알림

평일 아침 **7시 10분**, 나라장터(조달청) 입찰공고에서 축산물·급식 관련 공고를 모아
**청주에서 차로 1시간 안쪽 충북 기관** 공고만 골라 마감일·추정가격을 정리해 알려 줍니다.

```
[나라장터] 2026-11-27 청주권 축산·급식 공고 4건 (신규 2 · 마감임박 1)

🆕 신규 공고 — 2건
[물품] 2027년 학교급식 축산물(돈육) 공급 ★축산
  기관: 충청북도청주교육지원청 (청주, 약 0분)
  마감: 12/04(금) 10:00 D-7 · 개찰 12/04(금) 11:00
  추정가격: 1.2억원 · 제한경쟁 · 변경공고
  공고번호 R26BK00000001-001 · https://www.g2b.go.kr/...
```
(위 예시는 시험용 가짜 데이터입니다.)

## 무엇을 하나
| 단계 | 내용 |
|---|---|
| 수집 | 최근 28일 공고 중 공고명에 키워드가 있는 **물품·용역** 공고 (공사 제외) |
| 키워드 | 축산물·육류·정육·식육·한우·한돈·돈육·돼지고기·우육·쇠고기·소고기·계육·닭고기·오리고기 / 급식·식재료·식자재·주부식·부식류 |
| 제외 | 공고명에 공사·설비·기구·냉장고·세척기·차량·검사 등이 있으면 제외 (급식실 공사 같은 것) |
| 권역 | 수요기관 이름으로 시·군을 판단 → 청주·증평·진천·괴산·음성·보은·옥천·충주 (60분 이내). 영동·제천·단양 제외 |
| 정리 | 🆕 신규(어제 이후, 월요일은 주말 포함) / ⏰ 마감 D-3 이내 / 📋 진행 중 / ❓ 충북인데 위치를 못 찾은 공고 |
| 알림 | GitHub 이슈(메일·GitHub 앱 알림 자동) + 텔레그램(선택) |

마감 지난 공고, 취소공고는 빠지고, 정정공고는 최신 차수만 남습니다. `★축산`은 공고명에 축산 키워드가 있는 공고입니다.

## 설정 (한 번만)

### 1. 인증키 받기
1. [공공데이터포털](https://www.data.go.kr) 로그인 → **"조달청_나라장터 입찰공고정보서비스"** 검색 → **활용신청** (개발계정, 보통 바로 승인).
2. 마이페이지 → 활용신청 현황에서 **일반 인증키(Decoding)** 를 복사합니다. (Encoding 키를 넣어도 자동으로 변환합니다.)
   승인 직후 1~2시간은 키가 아직 등록 안 됐다는 오류가 날 수 있습니다.

### 2. GitHub에 키 넣기
저장소 → **Settings → Secrets and variables → Actions → New repository secret**
- `G2B_SERVICE_KEY` : 위 인증키

### 3. 알림 받기
- **GitHub 이슈 (기본)**: 공고가 있으면 매일 이슈가 하나 생깁니다. 저장소 상단 **Watch → All Activity** 로 해 두면 메일·GitHub 모바일 앱 알림이 옵니다.
- **텔레그램 (선택)**: 텔레그램 `@BotFather` 에서 봇을 만들어 토큰을 받고, 봇에게 아무 말이나 보낸 뒤
  `https://api.telegram.org/bot<토큰>/getUpdates` 에서 `chat.id` 를 확인해 Secrets에 넣습니다.
  - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`

### 4. 켜기
이 워크플로(`.github/workflows/g2b-monitor.yml`)는 **기본 브랜치(main)에 있어야** 매일 자동 실행됩니다.
병합한 뒤 **Actions → 나라장터 청주권 축산·급식 공고 알림 → Run workflow** 로 한 번 돌려 확인하세요.

## 고치기
모두 `config.json` 에서 합니다.
- 키워드 추가/삭제: `keywords`
- 걸러낼 단어: `exclude`
- 권역 넓히기/좁히기: `region.max_minutes` (예: 80으로 하면 영동 포함) 또는 `drive_minutes`
- 이름에 시·군이 없는 기관(❓로 뜨는 곳): `institution_aliases` 에 `"기관명": "시군"` 추가
- 공고가 없는 날도 알림 받기: `notify_when_empty: true`

## 내 컴퓨터에서 돌려 보기
```bash
G2B_SERVICE_KEY='인증키' python3 g2b-monitor/monitor.py
```
시험 데이터로: `python3 g2b-monitor/monitor.py --mock g2b-monitor/tests/sample_response.xml --now 202611270710`

## 알아둘 점
- **학교 급식 식재료 대부분은 나라장터가 아니라 aT 학교급식전자조달시스템(eaT)** 에서, 군 급식은 **국방전자조달(d2b)** 에서 입찰합니다. 이 알림은 나라장터 공고만 봅니다.
- 위치는 기관 **이름**으로 판단합니다. 이름에 시·군이 없는 기관은 ❓ 칸에 뜨니, 자주 나오면 `institution_aliases` 에 추가하세요.
- 이동 시간은 청주시청 기준 대략값입니다.
- 공공데이터포털이 해외 서버(GitHub Actions)의 접속을 막으면 Actions 실행이 "호출 실패"로 끝납니다. 그럴 땐 내 컴퓨터에서 예약 실행으로 돌리면 됩니다.
