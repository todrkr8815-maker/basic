# 방 안의 고양이

고양이 한 마리가 사는 방. `index.html`을 브라우저로 열면 바로 시작합니다. 설치할 것은 없습니다.

- **고양이 만들기**: 이름, 털 색, 무늬(단색·줄무늬·턱시도·삼색·포인트), 눈 색을 고릅니다.
- **밥**: 건사료, 습식 캔, 츄르. 먹으면 살이 찌고 기분이 좋아집니다. 배부른데 더 주면 더 찝니다.
- **안 주면**: 살이 빠지고 기분이 나빠집니다. 포만감 25 미만이나 기분 30 미만이면 **냉담 모드**가 되어 주인을 사람 취급하지 않습니다.
- **가출**: 굶주림이 길어질수록 가출 위험이 오르고, 계속 굶기면 실제로 문을 열고 나갑니다(굶기 시작해 14시간이면 반드시). 나간 뒤 72시간 안에 밥그릇을 채워 두면 돌아올 수도 있습니다.
- **명언**: 기분이 괜찮을 때 가끔, 묻지도 않았는데 하루와 삶에 대한 한마디를 합니다. 들은 말은 「명언 수첩」에 모입니다.
- **돌아다니기**: 고양이는 알아서 걷고, 앉고, 햇볕 든 자리나 방석에서 자고, 창밖과 문을 봅니다. 누르면 쓰다듬고, 바닥을 누르면 장난감 쥐를 던집니다.
- **시간**: 기본은 실시간이며, 창을 닫아 두어도 흐릅니다. 시험해 보려면 10배·60배로 바꾸세요.

저장은 이 브라우저(localStorage)에만 됩니다. 다른 브라우저나 기기에서는 처음부터 시작합니다.
