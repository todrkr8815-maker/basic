# 제갈량 상소문 (出師表)

매일 **오전 7시**, 그리고 **컴퓨터를 켜서 로그인할 때마다** 제갈량의 말투로 쓴 조언 창을 띄웁니다.

| 장 | 주제 | 분량 |
|---|---|---|
| 壹 | 클로드 코드 운용법 (초보자용 여덟 가지 계책) | 약 2,100자 |
| 貳 | 사업과 삶의 방향 | 약 2,100자 |
| 參 | 사진 작업 전반 | 약 2,100자 |

날마다 바뀌는 것:
- **오늘의 한 구절**: 제갈량의 「계자서」, 「출사표」 등에서 뽑은 문장 12개가 번갈아 나옵니다.
- **처음 펼쳐지는 장**: 세 장이 하루씩 돌아가며 먼저 나옵니다. (`1` `2` `3` 키나 탭으로 언제든 이동)
- **오늘의 계책**: 오늘 해 볼 일 하나. 체크하면 그날은 완료로 표시됩니다.

## 설치

저장소를 내려받아 **옮기지 않을 폴더**에 둔 뒤 설치하세요. 설치 후 폴더를 옮기면 다시 설치해야 합니다.

### Windows
1. `install-windows.bat` 을 더블클릭합니다.
2. 끝입니다. 바로 창이 한 번 뜨고, 다음 항목이 등록됩니다.
   - 작업 스케줄러 `ZhugeLiang-Memorial` — 매일 오전 7시
   - 시작프로그램 바로가기 — 로그인할 때마다
   - 바탕화면 바로가기 — 원할 때 직접 열기

창은 Edge(없으면 Chrome)의 앱 모드로 떠서 주소창 없는 독립 창처럼 보입니다.
해제하려면 `uninstall-windows.bat` 을 실행하세요.

### macOS
터미널에서:
```bash
cd 내려받은/폴더
./install-mac.sh
```
로그인할 때와 매일 오전 7시에 뜹니다. (잠자기 중이었다면 깨어날 때 뜹니다.) 해제는 `./uninstall-mac.sh`.

> 폴더를 `다운로드`, `문서`, `데스크탑`에 두면 macOS 권한 창이 뜰 수 있으니, 홈 폴더 바로 아래(예: `~/zhuge`)에 두는 것을 권합니다.

## 내용 고치기

본문은 모두 `index.html` 안의 `CHAPTERS`, `MAXIMS`, `STRATAGEMS`에 들어 있습니다.
- 빈 줄 = 문단 구분
- `## ` 로 시작하는 줄 = 소제목 (자동으로 第一計, 第二計… 번호가 붙습니다)

클로드 코드에게 "index.html의 사진 장에 ○○ 이야기를 추가해 줘"라고 부탁해도 됩니다.
